# Agent Instructions

Read `CLAUDE.md` at the repository root and follow it in full.

`CLAUDE.md` is the single source of project conventions for every agent
working in this repository: entry points, directory layout, build and test
methods, hard development rules, and workflow red lines. When this file and
`CLAUDE.md` disagree on anything, `CLAUDE.md` wins.

Also read **every file** under `.dev-method/` at the repository root before
starting any work item, and follow them: they carry the team collaboration
protocol, the working method for the current effort, and the channel rules
between roles. The directory is confidential, gitignored, local only, never
committed and never pushed; never copy its contents out and never reference
its path in any committed artifact. If the directory or a file in it is absent,
ignore that part and follow `CLAUDE.md` alone.

No work item starts before the Tech Lead has confirmed its approach with the
technical expert through the local channel; items without that confirmation stay
parked.
