## Typed witness source table

| item | source and layout |
| --- | --- |
| main rows | `u.main_rows` fixture messages of `u.code.ell` extension-field entries, each with `u.code.r` tail entries; encoded by `u.code` to `2^tree.log_n` symbols |
| mask rows | `u.mask_rows` fixture messages of the mask code's `ell` entries, each with its `r` tail; encoded by the mask code to `2^tree.log_n_zk` symbols |
| salts | one deterministic test salt per tree column (`tree.columns()`, `tree.salt_bytes`) |
| pads | generated by the sample-form rule from the seed and shape; deterministic test pads, not committed rows and not hiding |
| relation view | row-major flattening of the same main/mask message rows; tails are committed but not part of the relation view |
| tree part | a single part at index 0; part widths `main_rows * 3` and `mask_rows * 3`; code depths equal the tree depths |

The commitment is made by existing primitives only: `encode_row_fp3` for each
row and `RuntimeTree::commit(shape.tree, parts, salts)`. No new commitment
mechanism was added.

## Order and binding

1. Build the typed witness and commit it; fix `committed.root`.
2. Send the fixed root into the session.
3. Draw the independent seed.
4. Build the provider from the same `Arc<CommittedGuWitness>` and compute the
   complete ordered answers.
5. Register the pending sample claims and join record/column.
6. Transfer the same continuous chain to BAT and freeze the group.

A second root after the seed is rejected by the session; `from_committed_with_root`
also rejects a provider whose fixed root differs from the witness root.

## Independent checks and negatives

| check/negative | layer | result |
| --- | --- | --- |
| re-encode rows/tails and re-commit | independent encoding/commit | recomputed root equals the fixed root |
| sample-form answer on the shared relation | auxiliary plaintext oracle | equals provider answer and session sample target |
| provider/root same object | `Arc::ptr_eq` | true; not used as a substitute for the recomputation |
| different tagged witness | binding | different root; root-mismatch provider rejected (`StatementMismatch`) |
| unsupported multi-part shape | witness layout | `UnsupportedPrimitive` / `InvalidConfig` |
| syntactically valid wrong answer | verifier/SEND | registered pending; combined target changes; no rejection or truth decision |
| truncated answer list | pre-registration | `ShapeMismatch` |
| sample declaration in BAT | frozen BAT input | last target equals the sample answer; order plain×5, sample |
| root replacement after seed | session stage | `InvalidSessionState` (engine test) |

The auxiliary oracle is a test-only plaintext computation. The verifier does not
compare answers. A wrong answer can only be rejected by a later relationship or
proximity check, which is not connected; this is not a SEND truth check.
