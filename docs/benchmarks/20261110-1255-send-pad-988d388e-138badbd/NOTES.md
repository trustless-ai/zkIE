witness fixture"), based on `138badbd`. The production verify entry is unchanged.

## Pad semantics

| item | value |
| --- | --- |
| pad location | reserved slot in the mask message (`mask_code.ell - answers` for the demo single-row shape) |
| pad value | fixture value, encoded and committed before the seed |
| seed role | `beta` supplies the pad's coefficient in the sample-form linear equation |
| test | zero pad vs `0x1234` pad changes the committed root and the sample answer |
| relation/commit consistency | the same `mask_messages` entries are used for commitment and sample-form evaluation |
| hiding | none; deterministic public pad values are test-only |

The earlier "pad generated by seed" statement was incorrect and is fixed in the
module, NOTES and report.

## Witness fixture guarantee

- Fields are private; only canonical constructors (`new`, `new_with_tag`,
  `new_with_mask_pad`) create a witness.
- Each constructor derives `main_codewords`, `mask_codewords`, `relation` and
  `root` from the same stored rows/tails/salts.
- `from_committed` recomputes the root and relation and rejects a mismatch; a
  fixed root passed to `from_committed_with_root` must equal the witness root.
- The negative unit test `a_forged_relation_with_the_same_root_is_rejected`
  constructs a relation-only tamper with the same stored root and observes
  `StatementMismatch`.
- This is a test-local guarantee. It does not claim production unforgeability
  and must not be extended to a production witness/commitment path.

## Order, verifier and BAT

- Root fixed → seed → same shared witness → complete ordered answers →
  pending sample registration → record/column joins → same continuous chain to
  BAT.
- The verifier has no standard-answer comparison; a syntactically valid wrong
  answer remains pending, enters BAT and changes the combined target. Only a
  later relationship/proximity check could reject it; that check is not
  connected.
- Sample declaration remains in the BAT frozen input (last target).
- The 6-to-8 mask adapter and adapter-only downstream isolation remain.
